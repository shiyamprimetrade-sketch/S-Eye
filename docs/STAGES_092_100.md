real-application accuracy or expert-programmer equivalence. Human review is not
required for engineering continuation. Stage 84/91 comparators are preserved.

## Current S interface

`observe_interface` retains its defaults. With `region_proposals: true`, choose
`region_mode: baseline` (original Stage 91), `refined` (paired boxes plus actual
edge-stroke RLE masks), or experimental `color` (visible quantized-color masks).
These are unlabeled hypotheses. Color mode uses a dominant-border heuristic,
one-million-pixel/200,000-foreground-pixel budget and cannot recover hidden
instances or same-color overlaps. Refined mode caps mask workspace at eight
million combined region pixels and 20,000 runs. Mask runs are absolute source-grid
`[y, left, right_exclusive]`, with strict bounded decoding.

`extract_features` is a read-only schema-1 request with `image` and optional
`components: [legacy, interface]`. It returns a versioned schema, offsets, dimensions
and fingerprint. The legacy component has 91 values; interface has 23; combined
114. Existing learned models still use their original descriptor contract: the
new composite is not silently substituted. Additional extractors are registered
by trusted Python code, never imported from a JSON request. Invalid selections,
nonfinite vectors and dimension changes are rejected.

Optional `perspective_quad` and `canonical_size` normalize an image from known
caller-supplied corners before feature extraction; no automatic perspective or
corner detection is claimed. Original source identity and normalization provenance
remain separate. Filesystem grants, memory capability and child-worker deadlines
are unchanged; no host capture, clicks or keyboard actions are introduced.

## Batch evidence and remaining limits

- Full regression: **143 tests passed**; focused tests and generated reports exist
  separately for each stage, with a separate implementation commit per milestone.
- Boundary-pair benchmark on 33 frozen generated scenes: TP25/FP8/FN12 becomes
  TP25/FP0/FN12. The 12 overlap/low-contrast misses remain.
- Controlled bridge test: two parts, 15 bridge pixels explicitly removed.
- Controlled noise test: two isolated pixels removed, 100 foreground pixels kept.
- Gap test: one pixel introduced to restore an 18-pixel stroke; this can merge real
  adjacent regions and is an optional hypothesis, not a safe default correction.
- Stroke RLE round-trip IoU is 1 against the observed-edge grid. This verifies mask
  transport, not instance segmentation accuracy or full-object foreground.
- Two-color overlap test: visible masks contain 800 and 1,200 pixels. Depth order
  and hidden extent remain unknown; same-color overlap is one component.
- Caller-corner transform error is about 1.42e-14 pixels at four supplied corners.
  This measures the algebraic fit, not real photographic perspective invariance.
- All four supplied screenshots execute refined observation and combined feature
  extraction successfully, producing 114 finite features each. Proposal counts stay
  19/15/11/18: the small-gap pairing rule does not improve those screenshots. No
  real localization accuracy is inferred without an oracle.
