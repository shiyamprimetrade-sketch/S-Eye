# Stages 121–130: visual memory and scene evidence

Scoped engineering acceptance and generated measurements do not certify
representative application accuracy or persistent semantic object identity.

## Stage 121

Separate encoded source, decoded pixels, feature schema, model, observation and explicit session occurrence identities; hashes do not assert persistent real-object identity.

Implementation: src/seye/memory/identity.py, src/seye/integration/service.py, tests/test_stage121.py. Evidence: benchmarks/stage121_experiment.json and benchmarks/stage121_tests.txt.

## Stage 122

Persistent schema-specific balanced exact KD trees bind to authoritative observation snapshots and fail on stale/corrupt caches. Integrity/freshness checks remain linear, so end-to-end sublinear performance is not claimed.

Implementation: src/seye/memory/packet_index.py, tests/test_stage122.py, tests/memory_fixtures.py. Evidence: benchmarks/stage122_experiment.json and benchmarks/stage122_tests.txt.

## Stage 123

Schema-aware exact neighbor retrieval with explicit source exclusion, tie reporting and authoritative candidate checks; KD distance pruning does not remove linear integrity scans or prove object identity.

Implementation: src/seye/memory/packet_index.py, src/seye/integration/service.py, tests/test_stage123.py. Evidence: benchmarks/stage123_experiment.json and benchmarks/stage123_tests.txt.

## Stage 124

Persistent explicit caller-linked target histories separate session occurrence from observation identity and verify event provenance; no automatic cross-session object identity is claimed.

Implementation: src/seye/memory/history.py, src/seye/integration/service.py, tests/test_stage124.py. Evidence: benchmarks/stage124_experiment.json and benchmarks/stage124_tests.txt.

## Stage 125

Implementation: src/seye/memory/scenes.py, tests/test_stage125.py. Evidence: benchmarks/stage125_experiment.json and benchmarks/stage125_tests.txt.
