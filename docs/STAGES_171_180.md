## Verification evidence and limits

319 local tests passed, including all historical regressions. All ten controlled
workflow reports reproduced exactly on this host. Installed legacy CLI/Python/S
session smokes passed, and the new installed local CLI completed eleven commands
outside the checkout. Source-preservation audit and a development wheel build
passed; exact-head remote CI is recorded separately. Version 1.0 readiness is false.

Generated controls verify detached import bytes, exclusive output refusal,
source-grid overlay dimensions, hypothesis/report alignment, optional real
prototype inference with safely escaped training labels, five-record memory
pagination, source-bound unscored annotation validation, comparison denominators,
config grant preservation and malformed-input rejection. These are functionality
and integrity checks, not representative application recognition or accuracy.

The editor's Node VM checks use DOM/canvas/Blob test doubles in three cases:
1100-wide and 390-wide simulated layouts for a 500×300 source, plus a downscaled
800×533 preview of a 1200×800 source. Boxes map to the expected source coordinates
with zero measured error in these controls; download and undo pass. **No browser
rendering or actual mobile-device validation is implied.**

Real Chromium launch failed because its process-singleton socket was not permitted.
The shared browser also refused the local-file URL under its URL policy. No
browser-security workaround was attempted. `stages171_180_browser_status.json`
records this open item; independent human usability review is also unfulfilled.
Stage 179 closes its executable automated workflow harness, not that review gate.

Drafts never become generator truth or human-reviewed labels automatically.
Unlabeled comparisons report changes, not improvements; broad semantic recognition
remains unsupported. Main-S registration/deployment, live camera, Android hardware,
representative input validation, native process/filesystem security and release
acceptance remain open. Previous tracking and high-dimensional KD negatives remain.
