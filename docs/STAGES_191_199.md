release gate remains closed.

| 191 | Regression suite and installed CLI, Python API, spawned S session and local workflow smoke tests. The CI matrix installs the wheel it builds before running the checks. |

The held-out generated shape prototype got **0/3 known correct and 3/3
unknown rejected**. The linear model got **3/3 known correct and 0/3 unknown
rejected**. On a separate generated glyph test, centered SGD got 6/6 known
correct and rejected 4/4 unknowns. The two datasets measure different
conditions. The results leave representative recognition and unknown rejection
open. The 27-sequence association check used generated boxes and recorded 57
misses and 12 ID switches for the conservative tracker. Tracking in real
screens and camera inputs remains unverified.

## Verify the development wheel

With Python 3.12 or 3.13 and FFmpeg available, install the wheel from a passing
GitHub Actions job or build it from this checkout.

```sh
python -m pip wheel --no-deps . --wheel-dir dist
python -m pip install dist/seye_independent-0.1.0.dev199-py3-none-any.whl
seye-local --help
python -m unittest discover -s tests -v
python scripts/benchmark_independent_system.py --output system-report.json
python scripts/verify_final_checkpoint.py --experiment system-report.json --output final-checkpoint.json
python scripts/release_audit.py --checkpoint final-checkpoint.json --output readiness.json
```

Choose new output paths on each run. Local evidence is in
`benchmarks/stages191_199_checkpoint.json`, `benchmarks/stages191_199_tests.txt`
and `benchmarks/stages191_199_release.json`. Device performance, physical
camera operation, browser rendering and main-S deployment remain open.
