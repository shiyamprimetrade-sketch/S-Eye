## Verified learning contract and ablation

The old `geometry+appearance` representation and retired Stage 109 result remain
unchanged. The new optional `shape` component (`edge-centered-shape-v1`, 257 values)
crops observed edge support and normalizes its grid. It is suitable for the simple
single-glyph test; it is not a detector of arbitrary objects or a learned visual
representation. Older feature/model schemas stay compatible.

`experiments/stages111_120_protocol.json` was committed at Stage 111 before model
fitting: 9 generated training captures, 6 validation captures and 10 new test
captures, with new test positions and ring/diamond unknown designs. Capture IDs,
source-content identities and declared groups are separate. These captures share
a renderer and are correlated synthetic conditions, not representative independent
application photographs. Packet split checks do not certify near-duplicate scene
independence; source-image audits remain necessary for real datasets.

The linear learner starts from seeded independent random weights and runs explicit
SGD on fixed normalized features. Epoch selection uses validation loss only. Training
cross-entropy decreases from approximately 1.091245 to 0.00004955 in the 80-epoch
fixture. All parameters, seed/config, data identities and loss curves are retained.
Selected inference checkpoints restore scores exactly and refuse overwrite.
Mid-optimizer-state resumption is not claimed. Same-host same-input training is
reproducible; cross-platform byte identity is not promised.

| New generated test (6 known, 4 unknown) | Known correct | Unknown rejected |
| --- | ---: | ---: |
| Layout-based prototype comparator | 0/6 | 4/4 |
| Centered-shape prototype | 6/6 | 4/4 |
| Centered-shape SGD with prototype support gate | 6/6 | 4/4 |

This gain is associated with switching representation to the centered edge grid;
it does not prove centering alone is causal separately from descriptor type and
dimensionality. SGD adds no correctness improvement over the centered prototype
on this test. Unknown rejection also uses prototype support, so it is not credited
to softmax alone. Scores remain uncalibrated and truth probability is null. The
retired old 0/6 test is not relabeled or tuned to manufacture this new result.

Overfitting checks use fixed train/validation gap and loss-rise warnings; no warning
is not proof of generalization. Learning curves independently fit 1/2/3 examples
per category against the same validation set without test selection. The regression
gate requires identical test capture identity, recomputes outcome counts and refuses
to hide a loss in known recognition behind unknown-rejection gains (or vice versa).

## S integration and persistence

New schema-1 action `recognize_trained` accepts `image` and a selected inference
checkpoint in `model`. The trusted feature registry extracts the checkpoint's
schema; the learned classifier must agree with radius/margin prototype support.
Responses contain label/unknown, explicit rejection reasons, ranked raw scores,
source/model/schema hashes and no calibrated confidence claim. Read-root and
child-worker deadline controls remain. No mouse, keyboard or host capture actions
are introduced, and no main-S component is changed.

Optional `memory` also requires a write-root grant and `--allow-memory`. Stored
records retain the modular packet, structured decision and bound source/model
identities. Source pixels and weights are not embedded in these observation records.
Memory integrity checks enforce the new schema/provenance while preserving legacy
records. Old descriptor search skips modular packets instead of comparing incompatible
vectors; `memory_list` can return the records. Identity-aware retrieval is Stage 121+.

187 local tests pass, including the old batch-recognition regression. The full suite
caught a local-import shadowing bug in the new adapter; it is fixed with a distinct
predictor alias. Tests cover memory denial without a grant and verified reopen.
End-to-end scoped child-worker recognition, checkpoint restoration and private
observation persistence also passed. CI executes all ten new experiments and the
historical suite; exact-head remote evidence is tracked separately.
